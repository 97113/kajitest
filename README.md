# 漢字れんしゅう 5年

小学5年生向けの漢字書き取り練習アプリです。スマホ・iPad での利用を前提にした **HTML 1ファイル完結型**（`index.html`）で、外部ライブラリ・通信は一切使いません。

問題は、手持ちの漢字ドリル「たしかめテスト」9枚（各10問・計90問）をもとに、
**問題文・読み仮名・答えを分離して再構成**したものです。

---

## つかいかた

### 1. URLで開く（推奨）
GitHub Pages を有効にすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
Safari で開いて **共有 → ホーム画面に追加** すると、アプリのように起動できます。

> iOS では `file://` で開くと保存データ（履歴・途中経過）が消えやすいため、URL で開くほうが安全です。

### 2. ファイルを直接わたす（オフライン）
`index.html` を AirDrop・メール・iCloud Drive などでわたして開くだけでも動きます。

## 機能

| 機能 | 内容 |
|---|---|
| **3つの解答方式** | ①手書き＋自己採点 ②4択タップ（自動採点） ③○×だけ（頭の中で答える） |
| **即時採点** | 1問ごとに答えを表示 → ○/× |
| **まちがい再出題** | テスト直後に「まちがえた問題だけもう1回」 |
| **にがてリスト** | まちがえた問題を蓄積し、いつでもまとめて復習。**2回連続正解で卒業**（まちがえるとカウントは0に戻る） |
| **レジューム** | 1問ごとに自動保存。次回起動時に「つづきから／最初から」を選べる |
| **履歴** | 日時・範囲・点数の一覧／問題ごとの正誤／正答率の推移グラフ／よくまちがえる漢字ランキング |
| **出題単位** | プリント単位（10問）／全問からランダム（10・20問）／にがて問題だけ |
| **たて書き・よこ書き** | 設定で切替（たて書き＝ドリルと同じ見た目） |
| **よみあげ** | 端末の音声合成で問題文を読み上げ（漢字部分は読み仮名で読むため答えはバレません） |
| **おうちの人メニュー** | 全問題と答えの一覧／にがてリスト／学習サマリー／リセット（かんたんな計算でロック） |
| **バックアップ** | 履歴・にがてリストを JSON で書き出し／読み込み |

手書きした字は**採点後に破棄**します（保存すると容量上限で履歴が壊れるため）。

---

## データの保存について

- 保存先はブラウザの `localStorage`（キー: `kanji5.v1`）。端末内にのみ保存され、外部に送信されません。
- 端末を変えるときや、ブラウザデータを消す前には **設定 → バックアップを保存** を実行してください。

## 収録している問題

光村図書 5年（上）対応の漢字ドリル「たしかめテスト」より、9枚 × 10問 = **90問**。

| No. | 単元 | 教科書ページ |
|---|---|---|
| 8 | 銀色の裏地(1) | 上18〜29 |
| 12 | 銀色の裏地(2)／図書館を使いこなそう | 上30〜41 |
| 16 | 漢字の成り立ち(1) | 上42・43 |
| 20 | 漢字の成り立ち(2)／季節の言葉 春 | 上43〜45 |
| 24 | きいて、きいて、きいてみよう | 上46〜50 |
| 28 | 見立てる／原因と結果 | 上51〜63 |
| 34 | 敬語 | 上64・65 |
| 38 | 日常を十七音で／目的に応じて引用するとき | 上66〜77 |
| 42 | みんなが使いやすいデザイン／同じ読み方の漢字(1) | 上78〜85 |

答えは、記入済みページについては答案と赤ペンの丸つけを照合し、
**まちがっていた解答は正しい漢字に直して**登録しています。
未記入ページは読み仮名と文脈から答えを生成しました。

## 問題を追加・修正するには

`index.html` 内の `SETS` 配列を編集します。1問は次の形式です。

```js
// [前の文, 後の文, こたえ, 読み, 送り仮名フラグ]
["気持ちを", "する。", "想像", ["そう","ぞう"]]   // 漢字だけ（マスごとの読み）
["長い年月を", "。",   "経る", "へる", 1]         // 送り仮名つき〔  〕の問題
```

- 読みが配列のときは、答えの1文字ごとの読みとして各マスの上に表示されます。
- 最後の `1` は送り仮名問題の印です（答えは送り仮名まで含めて正解とします）。

4択モードの「にせもの」は `CONFUSE`（にた漢字の表）から自動生成します。
同訓異字など確実に出したい選択肢は `FORCED` に問題ID（例 `"s42-4"`）で指定できます。
